# IBM Plex Mono

This directory contains the unmodified IBM Plex Mono Regular and SemiBold
TrueType fonts.

- Release: IBM Plex v6.4.0.
- Revision: `383c681f015ed2626e919ec4e3cca16ccc204e9d`.
- Source: <https://raw.githubusercontent.com/IBM/plex/383c681f015ed2626e919ec4e3cca16ccc204e9d/IBM-Plex-Mono/fonts/complete/ttf/IBMPlexMono-Regular.ttf>.
- SHA-256: `fe11304a5fe956d5744e9b6a246cc83d90425245e75a62230044966ca96a7f50`.
- License: SIL Open Font License 1.1. See `LICENSE.txt`.
- Local changes: none.

SemiBold source:
<https://raw.githubusercontent.com/IBM/plex/383c681f015ed2626e919ec4e3cca16ccc204e9d/IBM-Plex-Mono/fonts/complete/ttf/IBMPlexMono-SemiBold.ttf>.
Its SHA-256 is `c9417148ce13f8fa7d2d5c9180bbc141f72aa0d814ffeb280f6904dc2b1bbd7a`.
The same revision and license apply to both weights.

The SP package includes the font and these records. The client loads the font
through the game filesystem. FreeType generates glyphs at the requested pixel
size. No desktop font installation or runtime download is required.
